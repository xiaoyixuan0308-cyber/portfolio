月度补货规划指标

从历史采购占比开始，逐步得到最终补货量和调整后库存天数。

需求与库存基础量
从历史采购、预测、当月采购和库存推导单个产品的需求速度。
历史占比

产品历史采购占比

同一渠道与产品分类范围内，单个产品过去 6 个月采购量占分类总采购量的比例；分母为 0 时按 0 处理。

产品历史采购占比=产品近6个月采购量所属分类近6个月采购总量\text{产品历史采购占比}=\frac{\text{产品近6个月采购量}}{\text{所属分类近6个月采购总量}}产品历史采购占比=所属分类近6个月采购总量产品近6个月采购量​
平均需求

产品三期平均需求量

将产品分类前两个月的实际采购量与当月预测量取平均，再按产品历史占比分配。

三期平均需求=历史占比×前两月实际采购量+当月分类预测量3\text{三期平均需求}=\text{历史占比}\times\frac{\text{前两月实际采购量}+\text{当月分类预测量}}{3}三期平均需求=历史占比×3前两月实际采购量+当月分类预测量​
采购预测

产品当月采购预测量

把产品分类的当月预测量按产品历史采购占比分摊。

产品当月采购预测量=历史占比×产品分类当月预测量\text{产品当月采购预测量}=\text{历史占比}\times\text{产品分类当月预测量}产品当月采购预测量=历史占比×产品分类当月预测量
剩余需求

产品当月剩余采购需求

从当月采购预测量中扣除已经发生的采购量，剩余需求不允许为负数。

剩余采购需求=max⁡(当月采购预测量−当月已采购量,0)\text{剩余采购需求}=\max(\text{当月采购预测量}-\text{当月已采购量},0)剩余采购需求=max(当月采购预测量−当月已采购量,0)
当前库存天数

当前库存天数

当月采购预测量为 0 时按 0 处理。

当前库存天数=期初库存当月采购预测量×30\text{当前库存天数}=\frac{\text{期初库存}}{\text{当月采购预测量}}\times30当前库存天数=当月采购预测量期初库存​×30
目标库存与理论补货
先在渠道与产品分类层计算配货后天数，再回到单个产品计算目标库存。
分类汇总

渠道与产品分类分组汇总

汇总当前渠道与产品分类下所有产品的指标。

分类库存=∑产品库存,分类剩余需求=∑产品剩余需求,分类平均需求=∑产品平均需求\text{分类库存}=\sum\text{产品库存},\quad\text{分类剩余需求}=\sum\text{产品剩余需求},\quad\text{分类平均需求}=\sum\text{产品平均需求}分类库存=∑产品库存,分类剩余需求=∑产品剩余需求,分类平均需求=∑产品平均需求
配货后天数

配货后预计库存天数

分类平均需求为 0 时按 0 处理。

配货后库存天数=分类库存+计划配货量−分类剩余需求分类平均需求×30\text{配货后库存天数}=\frac{\text{分类库存}+\text{计划配货量}-\text{分类剩余需求}}{\text{分类平均需求}}\times30配货后库存天数=分类平均需求分类库存+计划配货量−分类剩余需求​×30
目标库存

原目标期末库存

依据目标库存天数折算库存数量。

原目标库存=目标库存天数30×产品平均需求\text{原目标库存}=\frac{\text{目标库存天数}}{30}\times\text{产品平均需求}原目标库存=30目标库存天数​×产品平均需求
动态目标

动态目标期末库存

按渠道与产品分类配货后的整体天数折算到单个产品。

动态目标库存=配货后库存天数30×产品平均需求\text{动态目标库存}=\frac{\text{配货后库存天数}}{30}\times\text{产品平均需求}动态目标库存=30配货后库存天数​×产品平均需求
最终目标

最终目标库存

不允许调剂时，动态目标超过原目标的部分会被封顶。

最终目标库存={原目标库存,动态目标较高且不允许调剂动态目标库存,其余情况\text{最终目标库存}=\begin{cases}\text{原目标库存},&\text{动态目标较高且不允许调剂}\\\text{动态目标库存},&\text{其余情况}\end{cases}最终目标库存={原目标库存,动态目标库存,​动态目标较高且不允许调剂其余情况​
补货缺口

理论补货量

理论补货量不允许为负数。

理论补货量=max⁡(最终目标库存+剩余采购需求−期初库存,0)\text{理论补货量}=\max(\text{最终目标库存}+\text{剩余采购需求}-\text{期初库存},0)理论补货量=max(最终目标库存+剩余采购需求−期初库存,0)
配额调整与最终 库存天数
在渠道与产品分类分组内按计划配货量约束并进行余量调剂。
分类补货

产品分类理论补货汇总

汇总当前渠道与产品分类下所有产品的理论补货量。

分类理论补货量=∑各产品理论补货量\text{分类理论补货量}=\sum\text{各产品理论补货量}分类理论补货量=∑各产品理论补货量
基础补货

基础补货量

理论总量超过计划配货量时，按产品理论补货占比等比缩减。

基础补货量={产品理论补货量,分类理论补货量<计划配货量产品理论补货占比×计划配货量,其余情况\text{基础补货量}=\begin{cases}\text{产品理论补货量},&\text{分类理论补货量}<\text{计划配货量}\\\text{产品理论补货占比}\times\text{计划配货量},&\text{其余情况}\end{cases}基础补货量={产品理论补货量,产品理论补货占比×计划配货量,​分类理论补货量<计划配货量其余情况​
调剂补货

调剂后补货量

剩余配货量只在允许调剂的产品间按历史采购占比分配。

调剂后补货量={基础补货量,不允许调剂基础补货量+可调剂余量按历史占比分配,允许调剂\text{调剂后补货量}=\begin{cases}\text{基础补货量},&\text{不允许调剂}\\\text{基础补货量}+\text{可调剂余量按历史占比分配},&\text{允许调剂}\end{cases}调剂后补货量={基础补货量,基础补货量+可调剂余量按历史占比分配,​不允许调剂允许调剂​
调整后天数

调整后库存天数

产品平均需求为 0 时按 0 处理。调剂后补货量也是周度配货执行默认承接的月度补货建议量。

调整后库存天数=期初库存+调剂后补货量−剩余采购需求产品平均需求×30\text{调整后库存天数}=\frac{\text{期初库存}+\text{调剂后补货量}-\text{剩余采购需求}}{\text{产品平均需求}}\times30调整后库存天数=产品平均需求期初库存+调剂后补货量−剩余采购需求​×30

周度配货执行指标

承接月度补货建议，依次完成累计目标、库存分配、金额补差、约束和套包取整。

累计目标与库存分配
依据截至当前周的累计进度比例，将月度补货建议转换为周度累计目标并检查库存是否充足。
可用库存

中央仓可用库存

现有库存与在途库存相加后扣除必须保留的安全库存，可用量不允许为负数。

中央仓可用库存=max⁡(现有库存+在途库存−安全库存,0)\text{中央仓可用库存}=\max(\text{现有库存}+\text{在途库存}-\text{安全库存},0)中央仓可用库存=max(现有库存+在途库存−安全库存,0)
累计目标

渠道累计目标与待发量

根据本月截至基准日的实际发货量，计算当前仍需发出的数量。

渠道累计目标=月度补货建议×累计进度比例,渠道待发量=max⁡(累计目标−本月已发量,0)\text{渠道累计目标}=\text{月度补货建议}\times\text{累计进度比例},\quad\text{渠道待发量}=\max(\text{累计目标}-\text{本月已发量},0)渠道累计目标=月度补货建议×累计进度比例,渠道待发量=max(累计目标−本月已发量,0)
产品汇总

产品累计目标与待发汇总

针对同一产品，跨渠道汇总累计目标和待发需求。

产品累计目标=∑各渠道累计目标,产品待发汇总=∑各渠道待发量\text{产品累计目标}=\sum\text{各渠道累计目标},\quad\text{产品待发汇总}=\sum\text{各渠道待发量}产品累计目标=∑各渠道累计目标,产品待发汇总=∑各渠道待发量
目标完成率

已发占累计目标比例

产品累计目标为 0 时按 0 处理。

目标完成率=产品本月已发总量产品累计目标\text{目标完成率}=\frac{\text{产品本月已发总量}}{\text{产品累计目标}}目标完成率=产品累计目标产品本月已发总量​
库存状态

库存状态

同时考虑当前待发需求和其他渠道对同一产品的未清订单压力。

库存状态={不足,产品待发需求+其他渠道订单>可用库存充足,其余情况\text{库存状态}=\begin{cases}\text{不足},&\text{产品待发需求}+\text{其他渠道订单}>\text{可用库存}\\\text{充足},&\text{其余情况}\end{cases}库存状态={不足,充足,​产品待发需求+其他渠道订单>可用库存其余情况​
建议补货

库存约束后建议补货量

库存不足时，将扣除其他渠道订单压力后的可用库存，按各渠道待发需求占比分配。

建议补货量={渠道待发量,库存充足0,无剩余库存或无待发需求渠道待发占比×扣除订单后的可用库存,库存不足\text{建议补货量}=\begin{cases}\text{渠道待发量},&\text{库存充足}\\0,&\text{无剩余库存或无待发需求}\\\text{渠道待发占比}\times\text{扣除订单后的可用库存},&\text{库存不足}\end{cases}建议补货量=⎩⎨⎧​渠道待发量,0,渠道待发占比×扣除订单后的可用库存,​库存充足无剩余库存或无待发需求库存不足​
金额差额与系统调整
将建议数量转换为金额，与截至当前周的累计金额目标对比并按差异进行缩减。
调整边界

数量调整边界

同时计算产品可分配库存余额、目标库存缺口和补货后的预计库存天数，作为后续补差上限。

可分配库存余额=max⁡(可用库存−其他订单−已建议总量,0),目标库存缺口=max⁡(目标库存−当前库存−建议补货量,0)\text{可分配库存余额}=\max(\text{可用库存}-\text{其他订单}-\text{已建议总量},0),\quad\text{目标库存缺口}=\max(\text{目标库存}-\text{当前库存}-\text{建议补货量},0)可分配库存余额=max(可用库存−其他订单−已建议总量,0),目标库存缺口=max(目标库存−当前库存−建议补货量,0)
建议金额

建议金额

使用对应渠道和产品的采购单价计算建议金额。

建议金额=建议补货量×渠道产品单价\text{建议金额}=\text{建议补货量}\times\text{渠道产品单价}建议金额=建议补货量×渠道产品单价
金额目标

累计金额目标

将整月目标按周进度折算，再扣除截至当前周已经完成的实际金额。

累计金额目标=整月目标金额×累计进度比例,累计待发金额=累计金额目标−累计实际金额\text{累计金额目标}=\text{整月目标金额}\times\text{累计进度比例},\quad\text{累计待发金额}=\text{累计金额目标}-\text{累计实际金额}累计金额目标=整月目标金额×累计进度比例,累计待发金额=累计金额目标−累计实际金额
金额差额

建议金额差额

差额大于 0 时进入补差；差额小于或等于 0 时进入缩减调整。

建议金额差额=累计待发金额−建议金额合计,差额比例=建议金额差额整月目标金额\text{建议金额差额}=\text{累计待发金额}-\text{建议金额合计},\quad\text{差额比例}=\frac{\text{建议金额差额}}{\text{整月目标金额}}建议金额差额=累计待发金额−建议金额合计,差额比例=整月目标金额建议金额差额​
缩减数量

系统调整后数量

当建议金额明显超出累计待发金额时，按金额目标等比缩减并四舍五入。

系统调整数量={0,无待发金额或无建议金额round⁡(累计待发金额×建议数量占比),超额超过阈值原建议补货量,其余情况\text{系统调整数量}=\begin{cases}0,&\text{无待发金额或无建议金额}\\\operatorname{round}(\text{累计待发金额}\times\text{建议数量占比}),&\text{超额超过阈值}\\\text{原建议补货量},&\text{其余情况}\end{cases}系统调整数量=⎩⎨⎧​0,round(累计待发金额×建议数量占比),原建议补货量,​无待发金额或无建议金额超额超过阈值其余情况​
约束、补差与最终结果
补差按照库存天数、渠道、产品分类和产品编码排序逐行分配，并动态扣减产品级余额。
约束余额

月约束余额

周不能超时不追加补差；月不能超时受月度建议余额限制；无约束的重点产品可使用剩余可用库存。

月约束余额=max⁡(产品月度建议总量−已占用数量−产品待发汇总,0)\text{月约束余额}=\max(\text{产品月度建议总量}-\text{已占用数量}-\text{产品待发汇总},0)月约束余额=max(产品月度建议总量−已占用数量−产品待发汇总,0)
金额补差

金额补差量

仅存在正向金额缺口、允许调整且单价有效的记录参与，库存、约束和金额余额会逐行扣减。

金额补差量=max⁡(min⁡(库存余额,目标库存缺口,约束余额,⌊剩余待补金额产品单价⌋),0)\text{金额补差量}=\max\left(\min\left(\text{库存余额},\text{目标库存缺口},\text{约束余额},\left\lfloor\frac{\text{剩余待补金额}}{\text{产品单价}}\right\rfloor\right),0\right)金额补差量=max(min(库存余额,目标库存缺口,约束余额,⌊产品单价剩余待补金额​⌋),0)
补差数量

补差后数量

在原建议补货量上追加允许的金额补差数量。

补差后数量=建议补货量+金额补差量\text{补差后数量}=\text{建议补货量}+\text{金额补差量}补差后数量=建议补货量+金额补差量
最终发货量

最终建议发货量

金额不足时使用缩减后的数量，金额有缺口时使用补差后数量；配置包装规格后向下取整到整包。

最终建议发货量=⌊补差或缩减后的数量包装规格⌋×包装规格\text{最终建议发货量}=\left\lfloor\frac{\text{补差或缩减后的数量}}{\text{包装规格}}\right\rfloor\times\text{包装规格}最终建议发货量=⌊包装规格补差或缩减后的数量​⌋×包装规格
最终金额

最终金额与差额

用于衡量最终发货建议与累计待发金额目标之间仍存在的差异。

最终金额=最终建议发货量×产品单价,最终金额差额=累计待发金额−最终金额合计\text{最终金额}=\text{最终建议发货量}\times\text{产品单价},\quad\text{最终金额差额}=\text{累计待发金额}-\text{最终金额合计}最终金额=最终建议发货量×产品单价,最终金额差额=累计待发金额−最终金额合计
